Guides — pratiques, sans clic droit

Guides de téléchargement SVG

Une page moderne cache ses vecteurs à quatre endroits que le navigateur refuse d'enregistrer : <svg> en ligne, fonds CSS, références <use> de sprite, et sources <img> ou URI de données. Ces guides parcourent chacun d'eux, puis montrent la méthode à un seul popup qui les attrape tous — le balisage d'origine, pas une capture.
