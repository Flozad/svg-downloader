Guide — jeux d'icônes

Comment extraire les icônes SVG d'un site

Prendre une icône est facile. Prendre tout un jeu — chaque flèche, glyphe et logo qu'une page affiche, numéroté et dédoublonné — c'est à cela que sert ce guide.

La forme du problème

Un jeu d'icônes n'est pas un dossier de fichiers

Quand un site livre un jeu d'icônes, vous voyez rarement des fichiers. Vous voyez des composants. Chaque icône est un <svg> en ligne rendu par le framework, ou une référence <use> vers un sprite caché, ou un fond CSS. Enregistrer tout le jeu à la main, c'est ouvrir DevTools des dizaines de fois, copier du balisage, réparer des espaces de noms et inventer des noms de fichiers — pour un jeu qui peut compter soixante icônes.

SVG Downloader transforme cela en une seule analyse. Il lit la page rendue, détecte chaque icône comme du vrai balisage SVG — voyez comment marche la lecture en ligne — et vous laisse deux sorties : une icône à la fois avec le nom de votre choix, ou le jeu entier dans un seul ZIP.

Extraire le jeu — pas à pas

  1. Ouvrez la page du jeu d'icônes. Allez sur la vue qui affiche réellement les icônes — une galerie de composants, une barre de navigation, une grille de documentation. Ce que la page n'a pas encore dessiné n'est pas dans le DOM : assurez-vous que le jeu est à l'écran.
  2. Ouvrez le popup et analysez. Cliquez sur l'icône de la barre d'outils. SVG Downloader détecte les composants d'icônes SVG en ligne sur toute la page et liste chacun d'eux.
  3. Feuilletez le jeu. Utilisez Précédent et Suivant pour parcourir les aperçus isolés et confirmer ce que la page expose. C'est aussi votre vérification que tout le jeu est présent avant l'export.
  4. Nommez ceux que vous voulez à part. Pour une icône isolée, renseignez le nom de fichier facultatif, puis cliquez sur Télécharger le SVG courant pour qu'elle arrive en chevron-left.svg plutôt qu'en téléchargement (3).svg.
  5. Prenez tout le jeu en ZIP. Cliquez sur Tout télécharger en ZIP. Les icônes descendent d'un coup, dédoublonnées, et la ligne d'état du popup nomme tout ce qui n'a pas pu être résolu — voyez le guide ZIP pour le détail de cet export.

Pourquoi l'export du jeu entier est la voie rapide

La fonction ZIP en masse est faite exactement pour ça. Les jeux d'icônes regorgent de répétitions — la même flèche dans une douzaine de menus, un logo en en-tête et en pied — et une récolte naïve enregistrerait chaque instance. SVG Downloader dédoublonne les SVG identiques : l'archive reflète le jeu réel — soixante rendus peuvent faire quarante icônes uniques, et c'est ce que vous obtenez. Les fichiers sont numérotés dans l'ordre de la page — svg-1.svg, svg-2.svg — pour se déballer dans la séquence feuilletée dans l'aperçu, et le préfixe svg est modifiable dans les options de l'extension.

Ce sur quoi vous pouvez compter

  • Des vecteurs d'origine, pas des rendus. Chaque fichier est le SVG qui était dans la page — ses tracés exacts et son viewBox — chaque icône reste donc nette à toute taille et reste modifiable.
  • Espaces de noms réparés. Le xmlns manquant qui casse un SVG en ligne copié est remis, si bien que chaque fichier du ZIP s'ouvre dans Figma, Illustrator et VS Code.
  • Rien ne quitte votre machine. Toute l'extraction tourne sur l'appareil — pas de serveur, pas de compte, pas d'envoi, pas d'analytique.

Questions fréquentes

Comment enregistrer un jeu d'icônes entier, pas une icône à la fois ?

Ouvrez la page qui affiche le jeu et cliquez sur Tout télécharger en ZIP. L'extension réunit les SVG trouvés sur la page dans une archive, dédoublonnée : un jeu de quelques dizaines d'icônes descend en un clic.

Les icônes en double seront-elles enregistrées deux fois ?

Non. L'export ZIP dédoublonne les SVG identiques : une flèche de navigation présente à dix endroits est enregistrée une fois. L'archive reste propre et correspond à la taille réelle du jeu.

Puis-je contrôler les noms de fichiers ?

Pour une icône isolée, tapez le nom voulu avant de cliquer sur Télécharger le SVG courant et le fichier s'enregistre exactement sous ce nom. Un ZIP est numéroté à la place — svg-1.svg, svg-2.svg dans l'ordre de la page — et vous pouvez changer le préfixe svg comme bon vous semble dans les options, pour que le jeu arrive en acme-1.svg et suivants.

Trouve-t-il seulement les icônes en ligne, ou aussi les cachées ?

Il détecte les composants SVG en ligne, les icônes en fond CSS, les références <use> vers un sprite du même document et les sources <img> ou <object> y compris les URI data:. Si l'icône est affichée sur la page, elle est dans le périmètre. Les icônes que la page n'a pas encore chargées n'apparaîtront qu'une fois chargées.

Les icônes extraites restent-elles des vecteurs modifiables ?

Oui. Chaque fichier est le balisage SVG d'origine, tracés et viewBox intacts et espace de noms xmlns réparé : il s'ouvre et se modifie proprement dans Figma, Illustrator ou un éditeur de code.
