Guide — flux en masse

Téléchargez tous les SVG d'une page en ZIP

Prendre les icônes une par une va très bien pour une icône. Quand vous voulez tout le jeu — chaque logo, glyphe et illustration d'une page — SVG Downloader analyse le DOM et vous remet un seul ZIP de fichiers numérotés et dédoublonnés.

La tâche

Enregistrer d'un coup tous les SVG d'un site

Une seule page peut contenir des dizaines de SVG — un logo d'en-tête, une navigation pleine d'icônes, des glyphes de rubriques, des boutons sociaux, une marque de pied de page. Les enregistrer à la main, c'est trouver chacun, contourner le balisage en ligne et les fonds CSS, réparer les espaces de noms et inventer des noms de fichiers. Faites-le trente fois et vous avez perdu un après-midi.

Le flux en masse ramène tout à un clic. Vous pointez SVG Downloader sur la page, il récolte tout ce qui est vectoriel dessus, et il écrit le lot dans un ZIP. Les étapes ci-dessous sont toute la procédure.

Pas à pas : de la page au ZIP

  1. Installez et ouvrez le popup. Ajoutez l'extension gratuite à Chrome, Edge ou Brave, ouvrez la page voulue et cliquez sur l'icône SVG Downloader dans la barre d'outils. Tout tourne en local — rien de la page n'est envoyé.
  2. Laissez-le analyser. L'extension parcourt tout le DOM et rassemble les quatre sources de SVG : éléments <svg> en ligne, vecteurs en <img> et <object> y compris les URI data:, SVG en background-image CSS, et références <use> vers un sprite du même document. Vous pouvez les parcourir avec Précédent/Suivant pour confirmer la prise.
  3. Cliquez sur « Tout télécharger en ZIP ». Au lieu d'enregistrer un fichier, cela empaquette toute la collection dans une seule archive. Les icônes en double sont ramenées à un exemplaire en chemin : l'archive reflète le jeu, pas le nombre brut d'éléments de la page.
  4. Ouvrez l'archive. À l'intérieur, de vrais fichiers .svg, numérotés à partir de svg-1.svg dans l'ordre de découverte, chacun avec un xmlns réparé s'il manquait, prêt pour Figma, Illustrator ou VS Code sans retouche. Vous préférez un autre préfixe ? Réglez-le une fois dans les options de l'extension et toutes les archives suivent.

Ce qu'il y a dans le ZIP

Fichiers numérotés
svg-1.svg, svg-2.svg dans l'ordre de la page — avec un préfixe que vous choisissez dans les options, pour recevoir le jeu en acme-1.svg si vous préférez.
Dédoublonné
Les icônes qui se répètent dans la page sont enregistrées une fois. L'archive est le jeu d'icônes, nettoyé de ses copies.
Balisage d'origine
Chaque fichier est le vecteur qui était dans la page — tracés et viewBox préservés, espace de noms réparé. Pas un rendu recalculé.
Manques affichés
Le popup nomme tout ce qui n'a pas pu être résolu — d'ordinaire un fichier cross-origin bloqué ou un sprite externe — pour que rien ne disparaisse en silence.

Quel bouton

ZIP ou téléchargement unitaire

Les deux boutons vivent dans le même popup. Prenez celui qui correspond au travail.

  • Tout télécharger en ZIP — quand vous voulez tout le jeu, reconstruisez une bibliothèque d'icônes ou auditez ce qu'un site livre réellement. Un clic, une archive, aucune répétition.
  • Télécharger le SVG courant — quand vous avez feuilleté jusqu'à une icône précise avec Précédent/Suivant et qu'il ne vous faut que ce fichier. Pas d'archive, juste le .svg.

La voie en masse est documentée en entier sur la page de la fonction ZIP de page entière. Si vous poursuivez plutôt une icône récalcitrante, le guide extraire des icônes SVG déroule la voie fichier par fichier.

Bon à savoir

Questions sur le téléchargement ZIP en masse

Le ZIP contient-il des icônes en double ?

Non. SVG Downloader dédoublonne avant d'empaqueter : un logo ou une icône qui se répète dans la page est enregistré une fois, pas cinquante. Vous obtenez un jeu propre, pas le décompte brut de la page.

Qu'advient-il des SVG qui n'ont pas pu être enregistrés ?

La ligne d'état du popup les nomme par leur position dans la liste d'aperçus — Téléchargés 8 SVG sur 10. Ignorés : 3, 7. Les causes courantes sont un fichier cross-origin bloqué, ou une référence <use> pointant vers un fichier de sprite externe, non résolu. Les fichiers réussis se téléchargent quand même ; l'archive ne contient qu'eux, et la ligne d'état vous dit ce qui manque.

Faut-il utiliser le ZIP ou télécharger un seul SVG ?

Prenez Tout télécharger en ZIP quand vous voulez tout le jeu d'icônes ou que vous auditez un site. Prenez Télécharger le SVG courant quand vous avez feuilleté jusqu'à une icône précise et qu'il ne vous faut que ce fichier.
