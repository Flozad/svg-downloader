Questions fréquentes

SVG Downloader est-il gratuit ?

Oui. C'est gratuit et open source sous licence MIT. Pas d'offre payante, pas d'essai, pas de compte — tout tient dans l'extension que vous chargez dans votre navigateur.

Est-ce que mes données quittent mon navigateur ?

Aucun contenu de page ne sort. Détection, aperçu et téléchargement se font sur l'appareil. Pas de serveur, pas de compte, pas d'envoi, pas d'analytique ni de pistage. Deux choses sortent tout de même : les fichiers SVG que la page référence déjà, récupérés pour pouvoir être inclus dans un téléchargement, et le lien facultatif vers SVG Color Changer si vous choisissez de cliquer. Vos quatre préférences sont aussi conservées dans chrome.storage.sync et vous suivent d'une machine à l'autre via votre compte Google — des réglages uniquement, jamais du contenu de page ni un historique de navigation.

Dans quels navigateurs fonctionne-t-il ?

Chrome 88 ou plus récent, et les navigateurs Chromium actuels bâtis sur le même moteur — Microsoft Edge et Brave. Il se charge décompressé de la même manière partout ; seule l'adresse de la page des extensions change.

Pourquoi le clic droit ne permet-il pas d'enregistrer un SVG en ligne ?

Un <svg> en ligne fait partie du document, ce n'est pas une image avec sa propre adresse. Le navigateur ne propose Enregistrer l'image sous… que pour ce qu'il traite comme des images ; un SVG en ligne n'a donc aucune URL à enregistrer et l'option n'apparaît jamais. SVG Downloader le lit directement dans le DOM.

Le SVG copié depuis DevTools ne s'ouvre pas. Pourquoi ?

Presque toujours un espace de noms manquant. Le SVG en ligne compte sur l'analyseur HTML pour savoir que c'est du SVG, mais un fichier autonome exige un xmlns="http://www.w3.org/2000/svg" explicite. SVG Downloader le remet automatiquement : ses fichiers s'ouvrent partout, sans retouche.

Pourquoi l'icône téléchargée est-elle noire ?

Beaucoup d'icônes héritent leur couleur du CSS via currentColor, qui n'existe plus une fois le SVG isolé : il retombe donc sur le noir. Le fichier est correct — il n'a simplement aucune couleur figée. Pour verrouiller une couleur d'abord, passez par SVG Color Changer, puis enregistrez.

Puis-je télécharger un jeu d'icônes entier d'un coup ?

Oui. Cliquez sur Tout télécharger en ZIP : tous les SVG détectés sur la page sont réunis dans une archive, dédoublonnés pour éviter deux fois le même glyphe et numérotés à partir de svg-1.svg. Ce qui n'a pas pu être récupéré est signalé dans la ligne d'état du popup.

Fonctionne-t-il avec les sprites et les SVG en fond CSS ?

Oui. Au-delà du balisage en ligne, il résout les références <use> d'un sprite jusqu'au glyphe visé, et lit les SVG posés en background-image CSS, y compris les URI data: et les vecteurs en <img> ou <object>. Les quatre sources apparaissent dans le même popup.

Existe-t-il une version sur le Chrome Web Store ?

Oui. Elle est sur le Chrome Web Store sous le nom SVG Web Downloader & Extractor : l'installation tient en un clic. Vous pouvez toujours la charger décompressée depuis le dépôt si vous préférez exécuter les sources — la page Installation détaille les deux voies.

De quelles permissions a-t-il besoin ?

Quatre, toutes étroites. activeTab et scripting lui permettent de lire le DOM de la page courante, mais seulement au moment où vous ouvrez le popup. downloads lui permet d'écrire les fichiers que vous enregistrez. storage conserve vos quatre préférences — préfixe de nom de fichier, nom du ZIP, analyse à l'ouverture et lien vers l'outil de couleur — synchronisées via votre compte Google. Il n'a aucun accès en arrière-plan à vos autres onglets, et aucun contenu de page ni historique de navigation n'est stocké où que ce soit. Le détail complet est dans la politique de confidentialité.

Toujours bloqué ? Ouvrez un ticket sur github.com/Flozad/svg-downloader/issues, ou lisez la politique de confidentialité pour toute l'histoire des données.

Pas de compte, pas d'envoi, pas de piège

Gratuit, sous licence MIT, sur l'appareil. Chrome 88+, Edge et Brave.
