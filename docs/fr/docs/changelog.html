Ce qui a changé

Versions

Chaque changement notable, regroupé par version et listé du plus récent au plus ancien. L'extension suit une simple ligne de versions — aucune date n'est revendiquée, car le relevé honnête, c'est l'ordre, pas un calendrier.

v1.3 — actuelle

Renommage pour le store
Renommée en « SVG Web Downloader & Extractor » pour la fiche du Chrome Web Store, sans rien changer au fonctionnement de l'extension.
Console plus discrète
Sortie console allégée : l'extension ne bavarde plus dans les outils de développement lors d'un usage normal.
Script d'empaquetage
Ajout d'un script d'empaquetage produisant un bundle propre et prêt à être soumis au store.
Prêt pour la mise en avant
Correctifs en vue d'une mise en avant sur le Web Store — métadonnées et manifeste nettoyés avant publication de la fiche.

v1.2

Montée de version
Version d'entretien qui a incrémenté le numéro de l'extension et repris les correctifs précédents.

Améliorations antérieures

ZIP dédoublonné
La sortie Tout télécharger en ZIP dédoublonne désormais les SVG identiques : le même glyphe ne se retrouve plus deux fois dans l'archive.
Correction de mise en page
Correction d'un décalage de mise en page dans le popup : l'interface ne sursaute plus pendant que les aperçus et les contrôles se placent.

Version initiale

Détection multi-source
Détecte le SVG en ligne, les vecteurs en <img> et <object>, les SVG en background-image CSS et les références <use> vers un sprite du même document.
Aperçu et pagination
Aperçu isolé de chaque SVG avec navigation Précédent / Suivant et un nom de fichier personnalisé facultatif.
Téléchargement unitaire et ZIP
Télécharger le SVG courant pour un fichier, Tout télécharger en ZIP pour la page entière — avec l'espace de noms réparé et le balisage d'origine préservé.

L'historique complet des commits et les versions vivent sur GitHub. Vous avez trouvé une régression ? Signalez-la dans le gestionnaire de tickets.

Utiliser la dernière version

v1.3 — gratuite, sous licence MIT, sur l'appareil. Chrome 88+, Edge et Brave.
