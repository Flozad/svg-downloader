De quoi il s'agit

SVG Downloader est une extension Chrome qui trouve les SVG contenus dans une page web — balisage en ligne, vecteurs en <img> et <object>, images de fond CSS et références <use> vers un sprite du même document — et enregistre le fichier d'origine. Tout se passe dans votre navigateur : pas de serveur, pas de compte, pas d'envoi, pas d'analytique. Gratuit, sous licence MIT, actuellement en v1.3.

Ces docs sont volontairement courtes. Si vous voulez juste que ça marche, lisez Installation et Utilisation. Si quelque chose cloche, la FAQ couvre les suspects habituels.

Démarrage rapide

Il n'y a pas encore de fiche sur le Chrome Web Store. Quand elle y sera, l'installation tiendra en un clic ; d'ici là, chargez-la décompressée :

  1. Téléchargez ou clonez le dépôt depuis github.com/Flozad/svg-downloader.
  2. Ouvrez chrome://extensions dans Chrome, Edge ou Brave.
  3. Activez le mode développeur avec l'interrupteur en haut à droite.
  4. Cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier extension du dépôt.
  5. Ouvrez n'importe quelle page avec des icônes, cliquez sur le bouton SVG Downloader et enregistrez.

La marche complète — avec les notes Edge et Brave — se trouve sur la page Installation.
