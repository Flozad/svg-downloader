Fonctions — toutes les sources de SVG

Tous les SVG qu'une page cache, un popup

Un SVG peut se trouver dans une page de quatre façons, et la plupart mettent en échec le clic droit et Enregistrer l'image sous…. SVG Downloader connaît les quatre. Ouvrez le popup, voyez ce qu'il y a, enregistrez le fichier d'origine.

Le modèle commun

Quatre sources, un déroulé honnête

Les quatre sources sont différentes dans le DOM mais se comportent pareil dans le popup. Peu importe comment un SVG est arrivé sur la page, SVG Downloader le traite de la même façon une fois trouvé : le montrer, l'enregistrer, et vous dire ce qu'il a dû laisser de côté — sans toucher un serveur.

  • Un aperçu isolé de chacun. Chaque SVG trouvé est rendu à part, loin de la mise en page environnante, pour que vous puissiez feuilleter avec Précédent/Suivant et voir exactement ce que vous allez enregistrer avant de vous engager.
  • Le balisage d'origine, pas un rendu recalculé. Ce qui se télécharge, c'est le SVG qui était dans la page — ses tracés, son viewBox, sa précision. Il reste net à toute taille et reste du texte modifiable que vous pouvez recolorer, jamais une capture matricielle.
  • Entièrement sur l'appareil. Détection, aperçu et téléchargement se passent dans votre navigateur. Rien n'est envoyé, il n'y a pas de compte, et aucun appel d'analytique ne surveille ce que vous enregistrez.

Vous pouvez passer un fichier enregistré directement au SVG Color Changer pour le recolorer, ou envoyer la page entière vers un ZIP quand il vous faut tout le jeu. Commencez par la source qui correspond à l'icône devant vous.
