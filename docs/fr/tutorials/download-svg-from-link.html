Tutoriel — le piège du lien

Comment télécharger un SVG depuis un lien

Vous faites un clic droit sur le lien, choisissez Enregistrer la cible du lien sous…, et récupérez un fichier HTML de 40 Ko. C'est la façon la plus courante de repartir avec la mauvaise chose, et l'explication est simple.

Obtenir ce que le lien vise réellement

L'enregistrement n'utilise volontairement jamais Enregistrer la cible du lien sous… — parce que sur un lien pareil, cette entrée de menu est le piège plutôt que l'outil.

Ce que montre l'enregistrement

  1. Un lien qui pointe vers un vecteur, pas vers une page
  2. « Enregistrer la cible du lien sous… » vous donnerait l'enveloppe HTML
  3. Ouvrez le popup sur la page où se trouve le lien
  4. Le vecteur lié est dans la liste
  5. Donnez-lui un nom qui veut dire quelque chose
  6. Télécharger le courant — le fichier derrière le lien

Pourquoi la solution évidente échoue

Enregistrer la cible du lien sous… enregistre la réponse, quelle qu'elle soit

Votre navigateur n'a aucune idée de ce qu'il y a au bout d'un lien avant de demander. Enregistrer la cible du lien sous… n'inspecte rien — il récupère l'URL et écrit sur le disque ce qui revient, sous le nom que le lien suggère.

Alors quand le lien mène à une page de visualisation — une page de détail d'icône, une page « télécharger » avec un aperçu et un bouton — ce qui revient est du HTML. Vous obtenez un fichier nommé star.svg qui est en réalité une page web, d'où le mur de texte à l'ouverture, ou le refus d'ouvrir. L'extension n'a jamais eu tort ; c'est le lien qui n'a jamais visé un vecteur.

Trois formes de liens causent presque tout cela :

  • Un lien vers une page de visualisation. Le vecteur est à destination, pas au lien. Suivez-le, puis analysez cette page.
  • Un lien qui déclenche un téléchargement par script. Le href vaut # ou javascript:, et un gestionnaire de clic construit le fichier. Il n'y a rien à cette adresse à enregistrer.
  • Un lien qui enveloppe une icône en ligne. Ce sur quoi vous cliquez est le graphique, dessiné en balisage. Un clic droit vous donne le menu de la page — aucune option d'image, parce que le navigateur ne considère pas cela comme une image.

La méthode qui marche pour les trois

Arrêtez d'essayer d'enregistrer le lien. Enregistrez le vecteur depuis la page qui l'affiche — la réponse est la même, quelle que soit la forme devant vous.

  1. Suivez le lien s'il mène quelque part. S'il ouvre une page de visualisation ou de détail, laissez-le faire. C'est là que vit vraiment le vecteur, et c'est ce qu'il faut analyser.
  2. Ouvrez le popup sur la page où vous atterrissez. Cliquez sur le bouton de la barre d'outils. L'analyse se moque de savoir si vous êtes arrivé par un lien, par une recherche ou en tapant l'adresse.
  3. Trouvez-le dans la liste. Feuilletez avec Préc. et Suiv.. Sur une page de détail, le vecteur voulu est en général grand et évident dans l'aperçu.
  4. Nommez-le et téléchargez. Tapez un nom de fichier et appuyez sur Télécharger le courant. Vous obtenez un vrai fichier vectoriel, pas un document HTML déguisé en .svg.

Comment savoir ce que vous avez vraiment téléchargé

Si vous avez déjà un fichier suspect, cela prend dix secondes : ouvrez-le dans un éditeur de texte. Un vrai SVG commence par <svg ou une déclaration XML et pèse en général quelques kilo-octets. Une page HTML déguisée commence par <!doctype html> et est nettement plus grosse. Si c'est le second cas, le lien menait à une page, et analyser cette page vous donnera la vraie chose.

Quand le lien est l'icône

C'est la troisième forme, la plus courante sur les sites modernes — une icône cliquable qui est du balisage <svg> en ligne. Il n'y a réellement rien à enregistrer : pas d'adresse, pas de fichier, pas d'image que le navigateur reconnaisse. Soit vous analysez la page, soit vous faites un clic droit et prenez Enregistrer ceci en SVG dans le menu, ce que couvre le tutoriel de prise rapide.

Le piège
Enregistrer la cible du lien sous… écrit ce que l'URL renvoie — souvent du HTML.
La vérification
Ouvrez le fichier dans un éditeur de texte. <!doctype html> signifie que vous avez récupéré une page.
Le remède
Analysez la page qui affiche le vecteur, au lieu d'enregistrer le lien.

Questions fréquentes

Pourquoi Enregistrer la cible du lien sous… m'a-t-il donné un fichier HTML ?

Parce que le lien visait une page web plutôt qu'un fichier vectoriel. Enregistrer la cible du lien sous… récupère l'URL et écrit ce qui revient, sans vérifier ce que c'est — un lien vers une page de visualisation produit donc une page, enregistrée sous le nom .svg que le lien suggérait.

Le href du lien est juste # — où est le fichier ?

Il n'y en a pas. Un gestionnaire de clic construit le fichier en JavaScript au moment du clic. Rien n'existe à cette adresse à enregistrer : analyser la page pour y trouver le vecteur affiché est la seule voie.

Le lien est lui-même une icône et le clic droit n'offre rien d'utile.

Cette icône est du balisage SVG en ligne, que le navigateur ne traite pas comme une image : aucune option d'image n'apparaît donc. Soit vous ouvrez le popup et analysez la page, soit vous utilisez l'entrée « Enregistrer ceci en SVG » que l'extension ajoute au menu contextuel.

Arrêtez d'enregistrer des pages nommées .svg

Sortez plutôt le vecteur de la page — cela marche pour les trois sortes de liens.
