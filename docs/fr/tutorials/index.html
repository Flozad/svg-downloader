Si vous ne lisez qu'une chose

Pourquoi le navigateur ne l'enregistre pas pour vous

Un SVG sur une page moderne n'est presque jamais un fichier posé à une adresse. C'est l'une de quatre choses, et chacune met en échec Enregistrer l'image sous… à sa façon : du balisage <svg> en ligne dessiné droit dans le HTML sans URL derrière ; un background-image CSS que le navigateur traite comme décoration ; une référence <use> de sprite pointant dans un document caché ; ou une source <img> qui peut être un URI data: que le menu d'enregistrement massacre.

Tous les tutoriels d'ici fonctionnent pareil en dessous : lire le DOM vivant, résoudre ce que chaque vecteur est réellement, réparer l'espace de noms xmlns manquant, et vous remettre un fichier autonome. C'est pourquoi la méthode se moque de laquelle des quatre vous êtes tombé.
