Perguntas frequentes

O SVG Downloader é grátis?

Sim. É gratuito e de código aberto sob a licença MIT. Não há plano pago, período de teste nem conta — tudo se resume à extensão que você carrega no navegador.

Algum dado meu sai do navegador?

Conteúdo de página não sai. Detecção, prévia e download acontecem no dispositivo. Não há servidor, conta, upload, analytics nem rastreamento. Duas coisas saem: os arquivos SVG que a própria página já referencia, buscados para poderem entrar num download, e o link opcional para o SVG Color Changer, se você clicar. Suas quatro preferências também ficam em chrome.storage.sync, então acompanham sua Conta do Google entre máquinas — só configurações, nunca conteúdo de página ou histórico de navegação.

Em quais navegadores funciona?

Chrome 88 ou mais novo e os navegadores Chromium atuais feitos sobre o mesmo motor — Microsoft Edge e Brave. Ela é carregada descompactada do mesmo jeito em todos; só muda o endereço da página de extensões.

Por que não consigo salvar um SVG inline com o botão direito?

Um <svg> inline faz parte do documento, não é uma imagem com endereço próprio. O navegador só oferece Salvar imagem como… para o que ele trata como imagem, então um SVG inline não tem URL para salvar e a opção nunca aparece. O SVG Downloader lê direto do DOM.

O SVG que copiei do DevTools não abre. Por quê?

Quase sempre é namespace faltando. O SVG inline depende do parser de HTML para saber que é SVG, mas um arquivo isolado precisa de um xmlns="http://www.w3.org/2000/svg" explícito. O SVG Downloader devolve isso automaticamente, então seus arquivos abrem em qualquer lugar sem edição.

Por que o ícone que baixei está preto?

Muitos ícones herdam a cor do CSS via currentColor, que deixa de existir quando o SVG fica por conta própria, então ele volta ao preto. O arquivo está correto — só não tem cor gravada. Para fixar uma cor antes, use o atalho para o SVG Color Changer e depois salve.

Dá para baixar um conjunto inteiro de ícones de uma vez?

Sim. Clique em Baixar tudo em ZIP e ele junta num único arquivo todos os SVGs detectados na página, sem duplicatas para o mesmo glifo não aparecer duas vezes e numerados a partir de svg-1.svg. O que não pôde ser buscado é indicado na linha de status do popup.

Funciona com sprites e SVGs de fundo CSS?

Sim. Além do markup inline, ele resolve referências <use> de sprite até o glifo apontado e lê SVGs definidos como background-image no CSS, incluindo URIs data: e vetores em <img> ou <object>. As quatro origens aparecem no mesmo popup.

Existe versão na Chrome Web Store?

Sim. Está na Chrome Web Store como SVG Web Downloader & Extractor, então instalar é um clique. Você ainda pode carregá-la descompactada a partir do repositório se preferir rodar o código-fonte — a página Instalação mostra os dois caminhos.

De quais permissões ele precisa?

Quatro, todas estreitas. activeTab e scripting deixam ele ler o DOM da página atual, mas só no momento em que você abre o popup. downloads deixa ele gravar os arquivos que você salva. storage guarda suas quatro preferências — prefixo do nome, nome do ZIP, escanear ao abrir e o link da ferramenta de cor — sincronizadas pela sua Conta do Google. Ele não tem acesso em segundo plano às suas outras abas, e nenhum conteúdo de página ou histórico de navegação é armazenado em lugar nenhum. O detalhamento completo está na política de privacidade.

Ainda travado? Abra uma issue em github.com/Flozad/svg-downloader/issues ou leia a política de privacidade para a história completa dos dados.
