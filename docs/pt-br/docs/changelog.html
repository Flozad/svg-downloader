O que mudou

Versões

Toda mudança relevante, agrupada por versão e listada da mais recente à mais antiga. A extensão segue uma linha de versões simples — nenhuma data é reivindicada, porque o registro honesto é a ordem, não um calendário.

v1.3 — atual

Renomeação para a loja
Renomeada para “SVG Web Downloader & Extractor” na ficha da Chrome Web Store, sem mudar como a extensão funciona.
Console mais silencioso
Saída de console enxugada para que a extensão não tagarele mais no DevTools durante o uso normal.
Script de empacotamento
Adicionado um script de empacotamento que gera um pacote limpo e pronto para envio à loja.
Preparo para destaque
Correções rumo ao destaque na Web Store — metadados e manifesto arrumados antes da publicação da ficha.

v1.2

Aumento de versão
Versão de manutenção que subiu o número da extensão, levando adiante as correções anteriores.

Melhorias anteriores

ZIP sem duplicatas
A saída de Baixar tudo em ZIP agora remove SVGs idênticos, então o mesmo glifo não cai duas vezes no arquivo.
Ajuste de layout
Corrigido um deslocamento de layout no popup para que a interface não pule mais enquanto as prévias e os controles se acomodam.

Versão inicial

Detecção de várias origens
Detecta SVG inline, vetores em <img> e <object>, SVGs em background-image do CSS e referências <use> a sprites do mesmo documento.
Prévia e paginação
Prévia isolada de cada SVG com navegação Anterior / Próximo e um nome de arquivo personalizado opcional.
Download individual e em ZIP
Baixar o SVG atual para um arquivo, Baixar tudo em ZIP para a página inteira — com o namespace consertado e o markup original preservado.
