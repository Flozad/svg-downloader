O que é isto

O SVG Downloader é uma extensão do Chrome que encontra os SVGs de uma página web — markup inline, vetores em <img> e <object>, imagens de fundo CSS e referências <use> a sprites do mesmo documento — e salva o arquivo original. Ela roda inteiramente no seu navegador: sem servidor, sem conta, sem upload, sem analytics. Grátis, com licença MIT, atualmente na v1.3.

Estes docs são propositalmente curtos. Se você só quer que funcione, leia Instalação e Uso. Se algo parecer errado, as perguntas frequentes cobrem os suspeitos de sempre.

Início rápido

Ainda não há ficha na Chrome Web Store. Quando houver, instalar será um clique; até lá, carregue descompactada:

  1. Baixe ou clone o repositório em github.com/Flozad/svg-downloader.
  2. Abra chrome://extensions no Chrome, Edge ou Brave.
  3. Ative o Modo do desenvolvedor no botão no canto superior direito.
  4. Clique em Carregar sem compactação e selecione a pasta extension do repositório.
  5. Abra qualquer página com ícones, clique no botão do SVG Downloader e salve.

O passo a passo completo — com as observações de Edge e Brave — está na página Instalação.
