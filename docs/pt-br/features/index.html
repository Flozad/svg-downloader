Recursos — toda origem de SVG

Todo SVG que uma página esconde, um popup

Um SVG pode estar numa página de quatro maneiras, e quase todas derrotam o botão direito e o Salvar imagem como…. O SVG Downloader conhece as quatro. Abra o popup, veja o que há e salve o arquivo original.

O modelo comum

Quatro origens, um fluxo honesto

As quatro origens parecem diferentes no DOM, mas se comportam igual no popup. Seja qual for o jeito como um SVG chegou à página, o SVG Downloader o trata igual depois de encontrado: mostra, salva e conta o que precisou pular — sem tocar em nenhum servidor.

  • Uma prévia isolada de cada um. Todo SVG encontrado é renderizado sozinho, longe do layout ao redor, para você navegar com Anterior/Próximo e ver exatamente o que vai salvar antes de se comprometer.
  • O markup original, não uma re-renderização. O que baixa é o SVG que estava na página — seus traçados, seu viewBox, sua precisão. Continua nítido em qualquer tamanho e continua sendo texto editável que você pode recolorir, nunca um print rasterizado.
  • Inteiramente no dispositivo. Detecção, prévia e download acontecem no seu navegador. Nada é enviado, não há conta, e não há chamada de analytics vigiando o que você salva.

Você pode passar um arquivo salvo direto para o SVG Color Changer se quiser recolorir, ou mandar a página inteira para um ZIP quando precisar do conjunto completo. Comece pela origem que combina com o ícone à sua frente.
