Guias de download de SVG

Uma página moderna esconde seus vetores em quatro lugares que o navegador não deixa salvar: <svg> inline, fundos CSS, referências <use> de sprite e origens <img> ou data URI. Estes guias percorrem cada um e depois mostram o método de um popup só que pega todos — o markup original, não um print.
