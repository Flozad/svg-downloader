Se você ler só uma coisa

Por que o navegador simplesmente não salva para você

Um SVG numa página moderna quase nunca é um arquivo parado num endereço. É uma de quatro coisas, e cada uma derrota o Salvar imagem como… do seu jeito: markup <svg> inline desenhado direto no HTML sem URL por trás; um background-image do CSS que o navegador trata como decoração; uma referência <use> de sprite que aponta para um documento escondido; ou uma origem <img> que pode ser um URI data: que o menu de salvar estraga.

Todo tutorial aqui funciona igual por baixo: ler o DOM vivo, resolver o que cada vetor realmente é, consertar o namespace xmlns faltante, e te entregar um arquivo independente. É por isso que o método não liga para qual das quatro você calhou de encontrar.
