Qué cambió

Versiones

Todos los cambios relevantes, agrupados por versión y ordenados de la más reciente a la más antigua. La extensión sigue una línea de versiones sencilla: no se reclaman fechas, porque el registro honesto es el orden, no un calendario.

v1.3 — Actual

Renombrado para la tienda
Renombrada a «SVG Web Downloader & Extractor» para la ficha de la Chrome Web Store, sin cambiar el funcionamiento de la extensión.
Consola más silenciosa
Se recortó la salida por consola para que la extensión ya no parlotee en las herramientas de desarrollo durante el uso normal.
Script de empaquetado
Se añadió un script de empaquetado que genera un paquete limpio y listo para enviar a la tienda.
Preparación para destacados
Correcciones de cara a poder ser destacada en la Web Store: limpieza de metadatos y del manifiesto antes de publicar la ficha.

v1.2

Subida de versión
Versión de mantenimiento que subió el número de la extensión y arrastró las correcciones anteriores.

Mejoras anteriores

ZIP sin duplicados
La salida de Descargar todo en ZIP ahora elimina los SVG idénticos, así que el mismo glifo no acaba dos veces en el archivo.
Arreglo de maquetación
Se corrigió un salto de maquetación en el popup para que la interfaz ya no dé tirones mientras se asientan las vistas previas y los controles.

Versión inicial

Detección multiorigen
Detecta SVG en línea, vectores en <img> y <object>, SVG en background-image de CSS y referencias <use> a sprites del mismo documento.
Vista previa y paginación
Vista previa aislada de cada SVG con paginación Anterior / Siguiente y un nombre de archivo personalizado opcional.
Descarga individual y en ZIP
Descargar el SVG actual para un archivo, Descargar todo en ZIP para la página entera, con el espacio de nombres reparado y el marcado original intacto.
