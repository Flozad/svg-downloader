Story — founder / solo team

One icon set for the deck and the landing page, overnight

SM Sofia MarchettiFounder · pre-seed startup, team of two

“Investor meeting in the morning. My deck used one icon style, the landing page another, and a third had snuck in from a template. At 11pm I didn't want a design project — I wanted the set I'd already licensed for the marketing site to be the set on every slide. Consistently. Now.”

The setup

The problem was consistency, and the clock

Who
Sofia, a pre-seed founder doing design, marketing and everything else on a two-person team.
Stack
A no-code site builder, Figma slides, an icon set already in use on the live landing page.
The job
Get the whole icon set from the landing page as clean vector, once, so the deck and site finally matched.
The wall
The icons were baked into the builder's output as inline and background SVG — no download button, no source folder, and no time.

What wasn't working

“Grabbing icons one screenshot at a time at midnight is how you end up with fifteen slightly-different, slightly-blurry versions of the same arrow. I tried right-clicking a few — the no-code builder had rendered them as inline SVG and CSS backgrounds, so ‘Save image as…’ either didn't appear or saved a broken file. I did not have a second evening for this.”

The switch

Sofia opened her own live landing page, clicked SVG Downloader, and hit Download All as ZIP. The popup scanned the page, collected every vector — inline, background and sprite — de-duplicated the ones that repeated, numbered them, and dropped a single archive in Downloads. The status line named the couple it couldn't resolve so nothing was a silent miss.

“I unzipped one folder of clean SVGs, dragged them into Figma slides and the site builder, and every icon matched because they were literally the same files. They scaled to a full-bleed hero on slide one and a 20-pixel bullet on slide nine without blurring, because vector does that. I was in bed before midnight.”

“I budgeted an evening and it took a coffee. The deck looked like a company, not a weekend project — which, the night before a raise, is the entire game.”

— Sofia Marchetti, founder

The result

  • 1 ZIPthe whole page's icon set, de-duplicated and numbered
  • < 5 minfrom mismatched slides to one consistent set everywhere
  • Any sizefull-bleed hero to a tiny bullet, no blur — it's vector
What did the work
Download All as ZIP — the whole page in one click, de-duplicated, with unresolved items named in the status line. See the ZIP guide.
Why vector for slides
Raster icons blur when scaled up for a hero or projected on a wall. SVG stays sharp at every size. See vs. screenshotting.
A note on rights
Pulling icons from your own site — or a set you've licensed — is fair use of the tool. Mind the licence before reusing icons from a site that isn't yours.
