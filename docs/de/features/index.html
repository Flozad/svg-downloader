Funktionen — jede SVG-Quelle

Jedes SVG, das eine Seite versteckt, ein Popup

Ein SVG kann auf vier verschiedene Arten in einer Seite stecken, und die meisten davon hebeln Rechtsklick und Bild speichern unter… aus. SVG Downloader kennt alle vier. Popup öffnen, sehen, was da ist, Originaldatei speichern.

Das gemeinsame Modell

Vier Quellen, ein ehrlicher Ablauf

Die vier Quellen sehen im DOM verschieden aus, verhalten sich im Popup aber gleich. Wie ein SVG auch auf die Seite gekommen ist — einmal gefunden, behandelt SVG Downloader es gleich: zeigen, speichern und dir sagen, was übersprungen werden musste, ohne einen Server anzufassen.

  • Eine isolierte Vorschau von jedem. Jedes gefundene SVG wird für sich gerendert, weg vom umgebenden Layout, sodass du mit Zurück/Weiter blättern und genau sehen kannst, was du gleich speicherst.
  • Das Original-Markup, kein neues Rendering. Geladen wird das SVG, das in der Seite stand — seine Pfade, sein viewBox, seine Präzision. Es bleibt in jeder Größe scharf und bleibt editierbarer Text zum Umfärben, nie ein gerasterter Screenshot.
  • Vollständig auf dem Gerät. Erkennung, Vorschau und Download passieren in deinem Browser. Nichts wird hochgeladen, es gibt kein Konto, und kein Analyse-Aufruf beobachtet, was du speicherst.

Du kannst eine gespeicherte Datei direkt an den SVG Color Changer übergeben, wenn du sie umfärben willst, oder die ganze Seite als ZIP nehmen, wenn du den kompletten Satz brauchst. Fang mit der Quelle an, die zu dem Icon vor dir passt.
