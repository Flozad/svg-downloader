Hier anfangen

Worum es geht

SVG Downloader ist eine Chrome-Erweiterung, die die SVGs einer Webseite findet — Inline-Markup, Vektoren in <img> und <object>, CSS-Hintergrundbilder und <use>-Sprite-Referenzen im selben Dokument — und die Originaldatei speichert. Sie läuft vollständig in deinem Browser: kein Server, kein Konto, kein Upload, keine Analyse. Kostenlos, MIT-lizenziert, derzeit v1.3.

Diese Doku ist bewusst knapp. Wenn du es nur zum Laufen bringen willst, lies Installation und Bedienung. Wenn etwas seltsam aussieht, deckt die FAQ die üblichen Verdächtigen ab.

Schnellstart

Einen Chrome-Web-Store-Eintrag gibt es noch nicht. Sobald sie dort ist, genügt ein Klick; bis dahin lädst du sie entpackt:

  1. Lade oder klone das Repository von github.com/Flozad/svg-downloader.
  2. Öffne chrome://extensions in Chrome, Edge oder Brave.
  3. Schalte oben rechts den Entwicklermodus ein.
  4. Klick auf Entpackte Erweiterung laden und wähle den Ordner extension aus dem Repo.
  5. Öffne eine beliebige Seite mit Icons, klick auf den SVG-Downloader-Button und speichere.

Die vollständige Anleitung — mit den Hinweisen zu Edge und Brave — steht auf der Seite Installation.

Lieber von der Aufgabe her?

Die Anleitungen behandeln konkrete Aufgaben — ein SVG von jeder Website laden, einen ganzen Icon-Satz extrahieren oder alles als ZIP bündeln —, während diese Doku das Werkzeug selbst beschreibt.
