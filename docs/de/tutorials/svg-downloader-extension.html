Tutorial — Einrichtung

Die SVG-Downloader-Erweiterung, installiert und lauffähig

Eine Installation, ein Anheften und eine klare Antwort darauf, was sie sehen kann. Der letzte Teil lohnt das Lesen — eine Erweiterung, die Seiten lesen kann, verdient die Prüfung.

Erweiterung installieren Zu den Schritten ↓

Ansehen — 17 Sekunden

Von der Installation zum ersten Download

Das Anheften ist der Schritt, den Leute überspringen und sich dann fragen, wo der Button hin ist — Chrome versteckt neue Erweiterungen standardmäßig hinter dem Puzzleteil-Symbol.

Was die Aufnahme zeigt

  1. Einmal aus dem Chrome Web Store installieren
  2. Anheften, dann auf jeder Seite anklicken
  3. Sie verlangt activeTab — diese Seite, dieser Klick, sonst nichts
  4. Chrome, Edge und Brave führen sie alle aus
  5. Und es funktioniert in allen dreien gleich

Einrichtung

Installation auf Chrome, Edge oder Brave

Alle drei laufen auf Chromium, es ist also eine Erweiterung und ein Installationsablauf. Alles ab Chrome 88 funktioniert.

  • Chrome. Öffne den Eintrag im Chrome Web Store und wähl Zu Chrome hinzufügen, dann bestätigen.
  • Edge. Derselbe Eintrag. Edge fragt beim ersten Mal, ob Erweiterungen aus anderen Stores erlaubt sein sollen; stimm zu und installiere wie gewohnt.
  • Brave. Derselbe Eintrag, kein Extraschritt — Brave installiert direkt aus dem Chrome Web Store.

Dann anheften, und das ist der Schritt, der im Alltag wirklich zählt: Klick auf das Puzzleteil-Symbol in der Symbolleiste, such SVG Downloader und klick auf die Stecknadel. Ohne das räumt Chrome sie weg, und du klickst jedes einzelne Mal auf das Puzzleteil.

Installation und erster Lauf

Etwa vierzig Sekunden, das meiste davon ist das Laden der Store-Seite.

  1. Aus dem Chrome Web Store installieren. Wähl Zu Chrome hinzufügen — oder Edge, oder Brave — und bestätige die Berechtigungsabfrage.
  2. An die Symbolleiste anheften. Klick auf das Puzzleteil-Symbol, such SVG Downloader, klick auf die Stecknadel. Der Button sitzt jetzt dauerhaft in deiner Leiste.
  3. Öffne eine Seite mit Vektoren und klick auf den Button. Das Popup öffnet sich und scannt diesen Tab. Vor deinem Klick hat nichts die Seite beobachtet.
  4. Lade eines herunter, um es zu bestätigen. Blättere zu irgendeinem Icon, drück Aktuelles laden und sieh in deinem Download-Ordner nach. Damit ist die Installation verifiziert.

Was jede Berechtigung tatsächlich erlaubt

Fünf Berechtigungen, und keine davon ist die breite, um die sich Leute sorgen.

  • activeTab — sie kann die Seite im Tab lesen, in dem du bist, in dem Moment, in dem du ihren Button klickst, und weder vorher noch nachher. Das ist die wichtige: Es gibt keine Host-Berechtigung, ihr wird also kein Zugriff auf „alle deine Daten auf allen Websites“ gewährt, und sie läuft nicht still im Hintergrund auf jeder Seite, die du besuchst.
  • downloads — schreibt Dateien in deinen Download-Ordner. Für einen Downloader unvermeidlich.
  • contextMenus — ergänzt den Eintrag „Als SVG speichern“ im Rechtsklick-Menü.
  • scripting — injiziert den Code, der die Seite liest, auf Anforderung, nachdem du bereits geklickt hast.
  • storage — hält deine Einstellungen (Dateinamen-Präfix, ZIP-Name) lokal auf deinem Rechner.

Obendrein setzt die Content-Security-Policy der Erweiterung connect-src 'none', was ihren Seiten strukturell verbietet, eine Netzwerkverbindung zu öffnen. Das ist kein Versprechen, nicht nach Hause zu funken; es ist eine Konfiguration, unter der Nach-Hause-Funken nicht funktioniert. Und da sie MIT-lizenziert mit öffentlichem Quellcode ist, muss man nichts davon glauben.

Seiten, auf denen sie nicht läuft

Browser blockieren Erweiterungen auf ihren eigenen Seiten, und keine Erweiterung kann das übergehen: chrome://- und edge://-Einstellungsseiten, der Chrome Web Store und andere Add-on-Galerien sowie PDF-Dokumente. Dort sagt dir das Popup, dass es nicht auf die Seite zugreifen kann, statt stumm zu scheitern. Für lokale file://-Seiten kannst du in den Details der Erweiterung ausdrücklich Dateizugriff erteilen, wenn du ihn brauchst.

Firefox und Safari

Derzeit nicht. Das ist eine Manifest-V3-Chromium-Erweiterung; Firefox und Safari brauchen jeweils eine eigene Portierung und eine eigene Store-Prüfung, die nicht erfolgt ist.

Browser
Chrome 88+, Edge und Brave. Nicht Firefox oder Safari.
Schlüsselberechtigung
activeTab — dieser Tab, auf deinen Klick. Keine Host-Berechtigung.
Netzwerk
connect-src 'none' — sie kann strukturell nicht nach Hause funken.
Quellcode
MIT-lizenziert auf GitHub. Lies ihn oder bau ihn selbst.

Gut zu wissen

Häufig gefragt

In welchen Browsern läuft es?

Chrome 88 oder neuer, Edge und Brave — alle Chromium-basiert, eine Installation aus demselben Store-Eintrag. Eine Firefox- oder Safari-Version gibt es nicht.

Wo ist der Button nach der Installation hin?

Chrome versteckt neue Erweiterungen hinter dem Puzzleteil-Symbol. Klick darauf, such SVG Downloader und klick auf die Stecknadel, um sie in der Symbolleiste zu behalten.

Kann sie jede Seite lesen, die ich besuche?

Nein. Sie nutzt activeTab, das Zugriff auf den aktuellen Tab nur in dem Moment gewährt, in dem du ihren Button klickst. Es gibt keine Host-Berechtigung, sie läuft also nicht im Hintergrund auf anderen Seiten.

Schickt sie irgendetwas an einen Server?

Sie kann es nicht. Ihre Content-Security-Policy setzt connect-src auf none, was ihren Seiten verbietet, überhaupt eine Netzwerkverbindung zu öffnen. Der Quellcode ist öffentlich, falls du das prüfen willst.

Warum sagt das Popup, es könne auf diese Seite nicht zugreifen?

Du bist auf einer Seite, auf der Browser Erweiterungen blockieren — einer chrome://-Einstellungsseite, dem Chrome Web Store oder einer anderen Add-on-Galerie, oder einem PDF. Diese Einschränkung setzt der Browser durch und lässt sich nicht umgehen.
